# assets/images/

Drop your image files here. The site is already coded to use them.

## Required Images

| Filename | What it is | Size |
|---|---|---|
| `dfn-logo.png` | DFN Worldwide globe logo (transparent background) | 500×500px min |
| `book-cover-reset-system.jpg` | The Reset System book cover | 946×1662px (KDP size) |
| `book-cover-full-system.jpg` | Full System book cover | 946×1662px (KDP size) |
| `dfnchallenge-artwork.jpg` | DFNcHallenGe single/beat artwork | 3000×3000px (square) |
| `dfnstory-artwork.jpg` | DFNstory single artwork | 3000×3000px (square) |
| `dfnlegacy-artwork.jpg` | DFNlegacy single artwork | 3000×3000px (square) |
| `suave-portrait.jpg` | Your photo for the Founder section | Portrait, min 800×1000px |
| `og-image.jpg` | Social media share preview image | 1200×630px |

## Notes

- All images should be compressed before uploading (use squoosh.app — free)
- Keep file sizes under 300KB per image for fast load times
- The site handles missing images gracefully with placeholder text
- Square artwork for music should be exactly 1:1 ratio (Spotify requirement)

## Tools

- **Compress images:** squoosh.app (free, in browser)
- **Convert PNG to JPG:** squoosh.app
- **Resize:** squoosh.app
