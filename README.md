## Live Site

**GitHub Pages:** `https://[your-username].github.io/dfnworldwide`
**Custom Domain:** `https://dfnworldwide.com` *(connect in repo Settings → Pages)*

### To Deploy on GitHub Pages:
1. Go to your repo → **Settings**
2. Click **Pages** in the left sidebar
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save**
5. Your site is live in ~60 seconds

## Updating the Site

All content is in `index.html`. Links are in `script.js` under the `CONFIG` object at the top of the file — update your links there and they apply site-wide.

To add your cover images: drop them into `assets/images/` then update the `src` attribute in `index.html`.
